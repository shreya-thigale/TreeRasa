# Working as a beginner team

1. Pull the latest main branch before starting a feature.
2. Make a small branch, such as `feature/plant-notes` or `feature/vendor-reviews`.
3. Keep API routes, database models, React pages and ML services in their existing folders.
4. Comment on non-obvious decisions; prefer descriptive names over comments that repeat the code.
5. Never commit `.env`, user uploads, downloaded datasets, database dumps or trained model binaries.
6. Test one user journey end to end before merging it.
7. Record module ownership, open issues and each member's contribution for the final report/viva.
